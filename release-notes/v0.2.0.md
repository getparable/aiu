The first packaged Rust release of this fork adds a Windows system tray, a macOS menu bar icon, and a Linux AppIndicator, alongside the terminal interface and account panel.

Download the archive matching your platform:

- Windows x64: `x86_64-pc-windows-msvc.zip`
- Linux x64: `x86_64-unknown-linux-gnu.tar.gz`
- macOS Apple Silicon: `aarch64-apple-darwin.tar.gz`
- macOS Intel: `x86_64-apple-darwin.tar.gz`

Extract and run `aiu gui` (`aiu.exe gui` on Windows). Closing the panel keeps AIU in the tray; its menu provides Show, Refresh, and Quit. `SHA256SUMS` contains the archive checksums. macOS binaries are not notarized. Linux requires a compatible glibc (built on Ubuntu 22.04), GTK 3, AppIndicator runtime libraries, and a desktop tray host.

This release also addresses the credential and recommendation review:

- Rotated credentials are saved before hand-back and identity verification, with protected pending recovery after a failed import.
- Replacing credentials clears old authentication rejection without bypassing throttling.
- Active CLI logins remain CLI-managed; AIU adopts their updates and refreshes independent saved logins.
- Slow usage requests no longer hold the shared account-state lock.
- Explicit quota locks override unknown utilization; recommendations require recent evidence and prefer fresh usage.
- Codex JWT identity fallback produces consistent account keys.
- Retry-After supports seconds and HTTP dates.
- Browser denial ends sign-in immediately; the panel provides Cancel sign-in when a browser tab is closed.

Validation includes native Windows tray smoke checks, mock OAuth and usage protocol assertions, credential-failure and concurrency regressions, and Rust tests/builds for all packaged platforms. The original Go implementation and license remain in the repository under `legacy/`.
