AIU 0.3.1 stores tracked account credentials in one macOS Keychain item. This reduces access approval prompts for AIU's own credentials from one per account to one for the vault.

On the first run after upgrading, AIU copies existing account credentials into the vault. macOS may ask for access to each old item during that one-time migration. The old items remain in Keychain as recovery copies. You can run `aiu migrate-keychain` before opening the app to complete the migration explicitly.

This release also adds a Settings window when opening the app, an option to show its Dock icon, and a smaller banked-reset control in the menu bar panel.

If your AIU build is ad hoc signed, macOS may ask for vault access again after a later upgrade. A Developer ID signed build keeps the same signing identity across upgrades.
