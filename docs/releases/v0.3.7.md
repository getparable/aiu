AIU 0.3.7 fixes glass buttons overlapping the fixed header when scrolling the usage panel.

The header and account list now use separate glass containers, with the list's container inside the scroll view. Buttons retain their glass appearance and scroll with their account cards.

Builds now require Go 1.27.2, which fixes standard-library vulnerabilities reported by the release checks.

The Homebrew bottle is signed with Parable's Developer ID Application certificate. It is not notarized.
