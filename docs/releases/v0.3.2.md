AIU 0.3.2 fixes migration and concurrent updates for accounts stored in the shared macOS Keychain vault.

AIU now migrates credentials from every configuration directory that it opens, rather than only the first one. Processes using different `AIU_CONFIG_DIR` or `HOME` values coordinate updates to the same vault, so concurrent changes do not overwrite each other.

Automatic organization updates preserve the old Keychain items as migration backups. Removing an account still removes its active credential, and a later login can add it again. Existing v0.3.1 vaults remain readable.

The Homebrew bottle is signed with Parable's Developer ID Application certificate. Source builds may use an ad hoc signature when the signing certificate is unavailable; the bottle is not notarized.
