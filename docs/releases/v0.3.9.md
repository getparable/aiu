AIU 0.3.9 correctly identifies Codex sessions that OpenAI has ended.

When a token refresh returns 401 with "Your session has ended", AIU now marks the login expired and offers browser relinking. Cached usage no longer makes the account appear active after that rejection. Relinking lets the next usage fetch run immediately, without waiting out the five-minute polling interval.

Temporary server errors still remain retryable and do not require signing in again.

The Homebrew bottle is signed with Parable's Developer ID Application certificate. It is not notarized.
