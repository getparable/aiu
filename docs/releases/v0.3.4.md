AIU 0.3.4 applies Codex account switches to running sessions connected to its shared daemon.

After saving a different account, AIU checks for a running Codex app-server daemon and restarts it. Connected terminals reconnect and restore their conversations; current turns are interrupted. The restart affects every terminal attached to that daemon. Selecting the already saved account leaves the daemon running.

The CLI and Mac app report whether the daemon restarted, was unavailable, or failed to restart. A restart failure preserves the saved login and provides a manual recovery command. Standalone sessions (`--no-daemon`) and older Codex versions still need to exit and resume manually.

Daemon commands use the same `CODEX_HOME` as the switched credentials. The Mac app can find Codex in common installation locations even when launched from Finder; `AIU_CODEX_BIN` supports other executable locations. `aiu switch --json` reports the account and daemon outcome without credentials.

Validated with Codex 0.160.0 using synthetic accounts and a mock backend: the same terminal process retained its session ID and unsent draft, then used the selected account after reconnecting. Automated tests cover successful switches, unchanged accounts, unavailable daemons, failed and cancelled restarts, and failed credential writes.

The Homebrew bottle is signed with Parable's Developer ID Application certificate. It is not notarized; source builds may use an ad hoc signature when that certificate is unavailable.
