AIU 0.4.0 adds read-only Google Antigravity (`agy`) quota tracking alongside Claude and Codex.

Antigravity is tracked passively through Antigravity CLI's official `statusLine` hook (`~/.gemini/antigravity-cli/settings.json`). AIU does not store Google OAuth tokens, call undocumented Google endpoints, or switch Antigravity accounts.

Run `aiu add --agy` (or choose Antigravity in the Mac app's Add Account pane) to register `aiu hook agy` with `stack_with_default: true`, keeping Antigravity's built-in status line intact. If you already use a custom `statusLine` script, AIU leaves it untouched and prints the two lines to pipe into `aiu hook agy`.

Once enabled, `agy` feeds account email, plan tier, model-group quota windows, reset times, and AI credit balances into AIU's shared cache automatically while `agy` runs. `aiu --agy`, `aiu --json`, `aiu frontend`, and the macOS menu bar app display Antigravity windows as read-only (`canSwitch: false`) and detect elapsed window resets locally between CLI sessions.

The Homebrew bottle is signed with Parable's Developer ID Application certificate. It is not notarized.
